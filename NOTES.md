Use it for cross-task observations, useful reminders, recurring mistakes, and repo-level learning notes.

## Update Rules

1. Add notes only when they are useful beyond a single work session.
2. Keep notes grouped by topic.
3. Prefer short, clear bullets over long essays.
4. Link task IDs when a note came from a task.
5. If a note becomes important enough to change workflow, update `AGENTS.md` or the relevant template.

## Repo-Level Notes

### Project Meaning

- "Unlearning ML" means unlearning shallow memorized ML and rebuilding practical intuition from fundamentals.
- This repo is not primarily about the technical field called machine unlearning.
- The repo should function as a personal ML gym, revision system, and portfolio-quality learning record.

### Working Style

- Finish the active task before jumping to a new topic.
- Every serious task should compare against a dumb baseline.
- Documentation quality matters as much as model performance.
- A task is not complete until the tracker, progress log, experiment log, and report are updated.

### Task 001 Reminder

- Keep Task 001 focused on Linear Regression only.
- Ridge, Lasso, and ElasticNet belong in Task 002.
- The main learning goal is the regression workflow: load data, split, baseline, train, evaluate, plot residuals, report.
